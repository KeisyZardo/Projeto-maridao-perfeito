# 💌 O Jogo do Maridão Perfeito

Um quiz romântico e bem-humorado criado para testar o quanto alguém lembra dos detalhes de uma história a dois.

## 🎮 Funcionalidades
- 5 perguntas personalizadas.
- Respostas digitadas e múltipla escolha.
- Pontuação de até 50 pontos.
- Mensagens de feedback e resultado personalizado.
- Opção de jogar novamente.
- Layout responsivo.

## 🛠️ Tecnologias
- HTML5: estrutura da página.
- CSS3: estilos e layout responsivo.
- JavaScript: perguntas, validação, pontuação e interações.

## ▶️ Como executar
1. Baixe ou clone o repositório.
2. Abra `index.html` em um navegador.
3. Clique em “Começar o teste”.

## 📚 O que pratiquei
- Arrays de objetos, variáveis e funções.
- Condicionais e validação de entradas.
- Manipulação do DOM e eventos.
- Atualização da pontuação e da barra de progresso.

## 💗 Sobre
Projeto pessoal de aprendizado, desenvolvido para praticar conceitos de desenvolvimento web de forma criativa e divertida.
